## 4 皮肤体系落地：共享 token 层 + N 路切换（0.5.5.20261023）

Z.W. 流程：先网页预览选皮肤（`design/theme-preview.html`，6 选 2）→ 选定**琥珀暖调 + 薄荷青竹**（"暗夜霓虹/极简石墨跟现有的太像"）→ 落代码。

**预览页教训**：CSS 变量存裸三元组（配合 `rgb(var(--tint)/.5)`），但其它位置漏包 `rgb()` 共 22 处 → 整条声明无效、窗口背景透明，**只有存完整色值的桌面背景能切换**——局部正常掩盖全局失效。用负向断言 `(?<!rgb\()var\(--x\)` 批量修复。

**共享 token 层（实测驱动）**：加皮肤前核对两套现有皮肤，按钮/语义色/徽章/图标粉彩/选中行/GLASS_ALPHA **一字不差重复** → 抽 `S_*` 常量，各皮肤引用。**保留 Theme 字段不删**（136 处 `theme().C_XXX` 调用点零改动），取"字段保留+值引用常量"，单一数据源效果达成。新增皮肤只需填 11 个特有值（渐变对/footer/边框/文字层次2/玻璃2/图标/圆角）。

**4 处硬编码 → N 路**：
- `set_theme`: `if id==0 {0} else {1}` → `id.min(THEME_COUNT-1)`（顺带修了 theme.txt 手改成 99 会取野主题的隐患）
- `theme()`: 两分支 → 4 路 match（LLVM 跳转表，开销同级）
- `load_theme` 随机: `nanos&1` → `nanos % THEME_COUNT`
- main.rs 切换按钮: `1 - theme_id()` → `(theme_id()+1) % THEME_COUNT`

**新皮肤色值**（win-border 特意压暗防浅底锯齿，深空踩过的坑）：琥珀 (132,82,40)→(64,40,24) 边框(96,68,40)；薄荷 (24,118,106)→(12,58,60) 边框(44,92,88)。

**新回归 2 个**：`shared_tokens_identical_across_all_skins`（4 套共享字段逐项相等 + 特有字段确实不同 + 名称唯一）、`theme_switch_cycles_all_skins_and_clamps`（N 路循环 + 越界钳制）。53 测试全绿；verify PASS；部署 0.5.5.20261023；两套新皮肤截图目检通过（`tools/skin_{amber,mint}.png`）。

**过程坑**：Python 批量替换时 lambda 拼出 `S_C_ON_GRAD`（多一个 C_ 前缀），二次修正 `\bS_C_(?=[A-Z])` → `S_`（`S_CARD_*` 因 C 后非下划线不误伤）。
