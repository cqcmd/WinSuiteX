### 踩坑（Rust MSVC GUI 嵌入图标+版本+清单，纯 rc.exe 无 windres）
1. **egui_extras 0.28.1 `load_svg_bytes` 签名变了**：只收 `&[u8]` 返回 `ColorImage`（不再收 ctx/uri）。须 `cc.egui_ctx.load_texture(name, img, LINEAR)` 转 `TextureHandle`。
2. **build.rs 链接 app.res 必须用绝对路径**：链接器在 `target/release/deps` 跑，相对 `app.res` 找不到 → `cargo:rustc-link-arg=<CARGO_MANIFEST_DIR>/app.res`（用 `CARGO_MANIFEST_DIR` 拼）。
3. **版本资源整数 id 陷阱（关键）**：rc.exe 找不到 `winver.h`，把字面 `VS_VERSION_INFO` 当**字符串名**而非 `MAKEINTRESOURCE(1)`。结果 `FindResourceW` 查得到、`GetFileVersionInfoSizeW` 返回 **1813**（Explorer 属性→详细信息 也读不出版本）。修法：app.rc 顶部 `#define VS_VERSION_INFO 1` 再 `VS_VERSION_INFO VERSIONINFO`。
4. **FILEVERSION 第四段不能放 YYYYMMDD**：16 位字上限 65535，20260923 溢出 → rc 静默产出乱码数值（如 1.0.0.1）。数字段用 `0,1,0,0` 占位合法，完整「主.次.修订.日期戳」只放字符串 `VALUE "FileVersion","0.1.0.20260923"`（Explorer 显示字符串）。
5. **cargo 改 app.rc 后不重链 app.res**：app.res 是 build.rs 产物、非 cargo 跟踪的输入，仅 app.rc 变时 crate 不重编→不重链→exe 仍是旧资源。验证期用 `touch src/main.rs` 强制重链。
