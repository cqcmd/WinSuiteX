## AIDA64 跨报告对拍（mds 客户机）
用户提供 AIDA64 `Report.txt`（GBK）与我们的 `inventory.json` 对拍。结论：
- **一致**：CPU Ryzen 7 7800X3D / 主板 TUF GAMING B650M-PLUS / BIOS 3854·2026-04-03 / GPU RTX 5060 Ti / 磁盘 iCafe8 vDisk 150GiB(Shunwang Virtual SSD PRO) / 音频 USB+HD。
- **显示器**：一致（都是 Dell 360Hz）。AIDA64 给"通用即插即用监视器 [NoDB] (D3QZJV3)"+Model AW2724HF；我们 EDID 直读 `Dell（戴尔）A22E`(DELA22E) 更准。无需改。
- **网卡缺口（澄清后非 bug）**：我们 JSON 只列 1 块 `Intel 82599 10GbE 双口`（IP 192.168.0.17）。AIDA64 另列 `Realtek PCIe 2.5GbE Family Controller`。用户确认 Realtek 是**BIOS 中禁用**的——Windows 设备管理器无此设备，故 `GetAdaptersAddresses` 不枚举、我们漏列是**正确行为**（只报 OS 可见在用网卡）。⚠️ AIDA64 的"网络适配器"摘要行把 IP 192.168.0.17 标在 Realtek 上属其显示瑕疵；其**路由表**权威确认该 IP 属于 Intel 82599——与我们对齐。
- **设计原则再确认**：我们按 OS/固件可见设备采集（BIOS 禁用设备、firmware 幻影槽都如实反映），不做硬件级深扫；这与 AIDA64 硬件级扫描口径不同，非缺陷。
- 待办仍挂：① 第四十四轮 BIOS 日期修复未提交；② 内存容量偏差告警措辞（点名"固件幻影槽位"）尚未动手。
