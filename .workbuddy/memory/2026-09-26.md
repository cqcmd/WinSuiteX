  可能是驱动版本/老的 NVML 路径问题），报告渲染出「风扇 0% · 未知W · 利用 1%」。
- 根因：格式串里硬拼 `{}W`，`disp_u32(None)` 返回「未知」→ 拼成「未知W」。

  （有值「功耗 150W」/ 无值「功耗 未知」），文本与 HTML 共用、只换分隔符；
  顺手删掉因此不再使用的 `use std::fmt::Write as _`。
- 重渲验证（真机 JSON 用新 exe）：`未知W` → `功耗 未知`。
