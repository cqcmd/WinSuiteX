- `query_smart` 的 **SAS/SCSI 落点**与 **unsupported 早退分支（USB/RAID/iSCSI/虚拟）**均改为
  **先试 WMI**，拿不到才回退原「不可直采」DiskSmart。NVMe 内联块改为调用新函数，行为不变。
- 纪律守住：wear / power_on_hours 真 0 仍过滤为 None；健康态默认 Unknown；
  `health_percent = 100 - wear` 且饱和；source 标 `StorageReliabilityCounter`（可追溯，不是伪装成 ATA SMART）。

## 第三十六轮：厂商中文名收敛为单一数据源（01:40–01:55，commit `679cc00`）

### 架构约束（决定了单表放哪，别记错）
依赖图：**core 无依赖 / platform→core / report→core / cli→core+platform+report**。
**report 不依赖 platform** → 唯一数据源**只能放 `winsuitex-core`**；放 platform 则 report 取不到
（或被迫造出循环依赖）。

### 做法
- 新建 `crates/winsuitex-core/src/vendor_zh.rs`：`VENDOR_ZH` **117 条**（合并原 BRAND_DISPLAY 22 +
  vendor_zh MAP 75 + 磁盘 FULL 中文列 + 显示器 PnP 中文值 + 显卡 Matrox/ASPEED）。
  提供 `brand_zh()`（trim → 精确(忽略大小写) → **首词降级** → None）与 `brand_zh_or()`（未命中返回原文）。
- 四处改为委托 core，旧表删除：
  1. `platform/peripheral_db::brand_display` → 委托（`BRAND_DISPLAY` 已删，残留 0）
  2. `report::vendor_zh` → 仅转发（保留函数名，避免大改调用点）
  3. `report::disk_vendor_from_model` → `FULL` 降为两列 `(关键字, 英文)`，中文回查 core；
     **输出格式 `{英文} ({中文})` 保持不变**
  4. `platform/display::pnp_vendor` → 表改为 `(PnP码, 品牌key)`，如 `("DEL","Dell")`、`("SAM","Samsung")`

### 冲突与取舍（已如实处理，未静默二选一）
- **超微**：中文里同时指 Supermicro 和 AMD。维持原约定 `Supermicro→超微`、`AMD→AMD`（AMD 不译超微）避免歧义。
- **AOC**：统一到 `冠捷`（报告层本就是冠捷，PnP 层原输出英文 `AOC`）。因此**改动 2 处既有断言**：
  `pnp_vendor("AOC")→"冠捷"`、`monitor_model_from_device_id(AOC2769)` 厂商→`"冠捷"`。
  影响：AOC 显示器在报告里由英文 `AOC` 变为 `冠捷`（与 `SAM→三星` 现状一致，是收敛应有的效果）。
