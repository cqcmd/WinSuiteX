## 022 实机对比：C++"没问题"是没碰上，Rust 幽灵槽提示是有价值（答疑，未改码）

用户拿 022（EX-B650M-V7 PLUS / 7800X3D / Kingston 32G）的 C++ v1.6.7 截图（内存"已插 1 / 共 2"）对比 Rust 0.4.0 截图（含幽灵槽说明），问"为什么 Rust 有幽灵槽"。结论：
- C++ 与 Rust 读**同一张 SMBIOS Type 17**，解析逻辑对齐（hardware.cpp:216-255 vs smbios.rs::parse_mem，含 0x7FFF/0xFFFF Extended Size 处理）；C++ 无任何去重/过滤，遇固件说谎状态同样会数出"已插 2"。
- C++ 截图那次是**固件没说谎的时刻**：AM5 幽灵槽是间歇性固件缺陷（典型 S3 唤醒后出现，MSI 论坛实锤；052 幽灵在 CHANNEL A、022 在 CHANNEL B，哪条槽中招随机，符合间歇特征）。C++ 碰上幽灵状态会**静默显示 64GB/2 条**且无任何提示——不是没问题，是无法发现问题。
- 佐证：052 inventory.json（同板）固件虚报形态与 022 Rust 采集一致（一条全 Unknown 无 SPD + 一条 Kingston 全 SPD，OS 32427 vs SMBIOS 65536）。
- 现场验证法：让机器休眠唤醒（S3）后再跑冻结版 C++ exe → 应显示"已插 2/共 2"且无提示，即证明。
- 待决：Rust 内存段提示目前三段（标题小字 note + 通道提示 + 容量口径提示）偏重，若 Z.W. 觉得吵可合并为一条（幽灵场景三者同源）。
