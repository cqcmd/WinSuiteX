# WinSuiteX 硬件概览面板 v0.5.5

> 面向网吧 / 电竞酒店的本地硬件巡检工具 · 纯 Rust + GDI 自绘单 exe

## 核心特性
- **单 exe 零依赖**：约 830KB，双击即跑；无 dll、无 GPU、无运行时，VM / RDP 远程会话均可正常显示。
- **4 套皮肤体系**：深空玻璃 / 流畅灰紫 / 琥珀暖调 / 薄荷青竹，共享 token 层保证视觉一致。
- **圆角 AA 抗锯齿**：3× 超采样圆角与描边，零 dll 约束下逼近 GDI+ 平滑度。
- **控件 ZSUI 复刻**：开关 / 页签药丸 / WinUI 按钮度量，对标 qiu7824/zsui 精度。
- **三页硬件详情**：菜单 / 硬件 / 磁盘：CPU·主板·内存·显卡·网卡·音频·SMART 健康徽标·9 列磁盘明细。
- **启动提速**：先显加载页、采集移后台线程，双击到出窗约 0.04s。
