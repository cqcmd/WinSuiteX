【使用】
双击 winsuitex-gui-gdi.exe 即可运行，单 exe 零依赖、无需安装。
- 菜单页：系统概览与功能开关
- 硬件页：CPU / 主板 / 内存 / 显卡 / 网卡 / 音频 / 磁盘等硬件详情，含 SMART 健康徽标
- 磁盘页：分区格式(GPT/MBR) / 文件系统 / 簇大小 / 已用% 等 9 列明细
- 4 套皮肤：深空玻璃 / 流畅灰紫 / 琥珀暖调 / 薄荷青竹（随机或切换）

【说明】
- 读取板载声卡芯片等少数信息时会请求管理员权限；普通硬件信息无需提权。
- 纯本地运行，不上传任何数据。
- 兼容 Windows 10+，VM / RDP 远程会话均可正常显示。

【命令行版】
winsuitex.exe 为同产品的命令行版（v0.1.0），可用于脚本或批量采集。
