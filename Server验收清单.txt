WinSuiteX 真机验收清单（v1.0.2.20260724 / v5.1.5）
=========================================

【部署前提】
[ ] 系统为 Windows Server 2016 / 2019 / 2022（64 位）
[ ] 已安装「桌面体验（Desktop Experience）」角色
    （Server Core 无 Explorer，右键菜单根本不会出现，属部署前提非缺陷）
[ ] 以管理员身份运行 WinSuiteX.exe（右键 → 以管理员身份运行）

【功能启用】
[ ] 运行后 GUI 出现「命令提示符」「显示/隐藏 系统文件」两项
[ ] 点击启用，提示成功（无注册表拒绝报错）

【右键菜单验证】
[ ] 文件夹上右键 → 出现「命令提示符」「显示/隐藏 系统文件」
[ ] 文件夹空白处右键 → 同样出现
[ ] 桌面空白处右键 → 同样出现

【功能验证】
[ ] 点击「显示/隐藏 系统文件」→ 资源管理器中系统文件显隐切换正常
[ ] 深层目录（路径 > 260 字符）右键「命令提示符」→ 终端能 pushd 进入、不闪退
    （这是 v5.1.2 内存安全修复点：改用堆串路径，避免 MAX_PATH 截断）
[ ] 命令提示符打开后当前目录为右键所在目录

【异常排查】
[ ] 菜单不显示：确认桌面体验角色、是否管理员运行、是否为 64 位系统
[ ] HKLM 写入失败：确认 UAC 已提权（exe 自带 requireAdministrator 清单）
[ ] 功能失效：在 GUI 停用后重新启用一次
